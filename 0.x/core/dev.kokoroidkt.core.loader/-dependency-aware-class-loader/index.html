DependencyAwareClassLoader

open class DependencyAwareClassLoader(jarFile: File, dependencyClassLoaders: List<ClassLoader>, extensionName: String? = null) : ExtensionClassloader

A custom ClassLoader with delegation order: JVM Application ClassLoader → Dependency ClassLoaders → Self (JAR).

Unlike standard parent-first delegation, this classloader:

  1. Checks if the class is already loaded

  2. Delegates to the JVM system/application ClassLoader

  3. Tries each dependency ClassLoader in order

  4. Falls back to loading from the self JAR

Parameters

jarFile

the extension JAR file to load classes from

dependencyClassLoaders

ordered list of dependency ClassLoaders

extensionName

human-readable extension name used as logger prefix
